# magritte.io
principe du plaisir

A web-based novel — essays, short stories, journal entries, fragments and transmissions —
written as a neo-surrealist response to the acceleration of machine intelligence and the
commoditization of the self.

**[BRAND.md](./BRAND.md)** is the binding brand, design and build specification.
