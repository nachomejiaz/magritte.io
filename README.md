# magritte.io
principe du plaisir

A web-based novel — essays, short stories, journal entries and fragments —
written as a neo-surrealist response to machine intelligence and the
commoditization of the self.

- **[BRAND.md](./BRAND.md)** — brand and build specification.
- **`site/`** — draft site with placeholder text. Static pages; open `site/index.html`
  or serve the directory. Every page works with JavaScript disabled.
- **`build.py`** — regenerates `site/` and `preview.html` from the content list at the
  top of the file. `python3 build.py`
